Time Series Anomaly Detection from CT Frames
Note: Only partial code is provided due to confidentiality.
Overview
This project focuses on extracting key points from CT frames within a heartbeat cycle and building transformer models enhanced with graph convolution layers for binary classification to detect anomalies in time series data.
Key Contributions
Extracted time series features from CT frames for anomaly detection.
Implemented transformer + graph convolution models for binary classification.
Demonstrated data preparation, model integration, and evaluation methodology.
Developed using PyTorch for scalable and reproducible experiments.
